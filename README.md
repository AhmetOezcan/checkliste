# Energy Storage System Checklist

A modern, responsive web-based checklist for technical planning and evaluation of energy storage systems.

This project was developed as a freelance solution to digitize and simplify complex technical requirements into a structured and user-friendly interface.

---

## Features

- Structured checklist for energy storage systems  
- Input fields for technical specifications  
- Parameters like temperature range, C-rate, altitude  
- Visual connections between system components  
- Fully responsive modern UI  

---

## Tech Stack

- HTML  
- CSS  
- JavaScript  

---


## Freelance Project

This project was developed for a client to replace manual and paper-based system planning with a digital solution.

The goal was to:
- simplify technical workflows  
- improve data consistency  
- create a clear and intuitive interface for complex systems
